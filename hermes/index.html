Hermes Personal Automation

A private, single-user Google Workspace integration

What this application does

Hermes is a personal automation agent installed and operated by the site owner on their own computer. It connects to the owner's own Google account using Google's official OAuth 2.0 API to assist with everyday tasks such as:

  • Morning email review — summarising recent Gmail messages so the owner can start the day informed;
  • Calendar awareness — listing upcoming Google Calendar events and preparing meeting notes;
  • Document tasks — reading and drafting Google Docs, Sheets and Drive files at the owner's explicit request.

Who uses this application

This application is for personal use only and serves a single user: the account owner who authorised it. It is not a public service, collects no sign-ups, and no other accounts can use it. As permitted by Google's verification policy for personal-use apps (fewer than 100 users), this application operates without formal Google verification, and Google will show an "unverified app" notice at sign-in.

Google API services used

The application uses Google's OAuth 2.0 platform and the Gmail, Google Calendar, Google Drive, Google Sheets, Google Docs and Google People (Contacts) APIs. It only accesses data belonging to the Google account that granted consent, and only when the owner asks it to perform a task.
